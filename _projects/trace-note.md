## 시작점

앱과 서버의 로그가 다른 파일에 남으면 요청 하나를 따라갈 때도 두 창을 오가야 한다. Trace Note는 두 파일을 같은 시간축에 놓고 읽는 도구다.

## 읽는 방식

각 줄에 시각, 출처, 메시지를 표시한다. 시각이 같으면 파일 안의 원래 순서를 유지하고, 시각을 읽을 수 없는 줄은 따로 모은다. 요청 ID를 선택하면 그 요청에 해당하는 줄만 남는다.

## 구현 메모

요청 ID 열을 선택했을 때는 해당 요청의 이벤트만 추린다. 아래는 필터의 핵심을 단순화한 예시다.

```python
def events_for_request(events, request_id):
    return [event for event in events if event["request_id"] == request_id]
```

## 다음 실험

서로 다른 시간대를 쓰는 서버 두 대의 로그를 섞어 볼 예정이다. 같은 순간을 가리키는 두 줄이 나란히 놓이는지 확인하면 시간 변환 과정도 점검할 수 있다.
